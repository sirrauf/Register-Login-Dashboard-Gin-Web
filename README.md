# Cara Run web server:
1. [Download Golang](https://go.dev/dl/)
2. Jalankan runwebserver.exe di folder projects.
3. Selesai.

# Cara kontribusi:
1. [Download Golang](https://go.dev/dl/)
2. [Download Visual Studio Code] (https://code.visualstudio.com/)
3. Download Gin Framework dan Mod Golang dengan cara ketik di cmd dalam folder project: Mod: go mod init dashboardapp
Web Framework Gin: go get github.com/gin-gonic/gin, ORM Gorm:go get -u gorm.io/gorm Driver Mysql: go get -u gorm.io/driver/mysql
